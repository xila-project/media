# Xila Media Implementation Plan

**Goal:** A functional, reproducible media foundation with a verified trailer and startup processing pipeline.
**Architecture:** Motion Canvas scenes rendered through its browser Renderer; FFmpeg encodes frames. Optional Blender imports exact official SVG curves. Ignored brand cache is resolved from an immutable commit with SHA-256 verification.
**Tech stack:** Node 24.22.0, Motion Canvas 3.17.2 (MIT), TypeScript, Python, FFmpeg, optional Blender.
**Spec:** User mission in this session; autonomous execution explicitly requested.

## Global constraints
- Brand v2.0.0 geometry, Montserrat, monochrome, clear space; never alter sibling repositories.
- No paid generation, credentials, or generated media committed.
- 1920x1080, 30 FPS, English trailer; explicitly labelled placeholder footage.

## Review focus
- Invalid CLI dimensions/rates must fail before rendering.
- Brand cache must reject corrupt assets and preserve exact upstream bytes.
- Missing recordings must remain visibly labelled placeholders.
- Audio exports must be mono signed PCM16 at requested rate and bounded peak.
- CI must use the same local commands with optional Blender isolated.
